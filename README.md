## 一、哲学常识
1. **奥卡姆剃刀原理**：若无必要，勿增实体。在多种解释中，选择最简单的。
2. **幸存者偏差**：我们看到的往往是筛选后的结果，而非真相的全貌。不要只听成功者的经验。
3. **批判性思维**：分清“事实”和“观点”。事实是客观存在的（实然），观点是主观可变的（应然）。
4. **第一性原理**：剥离事物的表象，回到最基本的真理，然后从头开始推导。
5. **归纳与演绎**：人类只能通过归纳间接认识世界，只能证伪，不能保真。演绎法是在归纳得到的假设来进行逻辑推理得到等价于原假设的结论。归纳是0到1，演绎是1到10，所有都不保真，人只能求可不求真，所有的事物的可信度都是0到99.99%。

## 二、经济常识
1. **钱的本质**：钱是“白条”，是社会资源的索取权。它的价值在于信用和交换能力。
2. **机会成本**：做一件事的成本，是为了它而放弃的其他最高价值的选择。
3. **复利效应**：世界第八大奇迹。长期的、微小的、持续的正向增长，最终会产生爆发性的结果。
4. **边际效用递减**：随着同一种东西消费量的增加，每增加一个单位带来的快乐/满足感会越来越少。
5. **沉没成本**：已经付出且无法收回的成本（时间、金钱、情感），不应作为未来决策的依据。

## 三、人性常识
1. **趋利避害**：这是生物的本能。不要试图对抗人性，而要顺应人性去设计激励机制。
2. **损失厌恶**：丢掉 100 块钱带来的痛苦，远大于捡到 100 块钱带来的快乐。
3. **归因偏差**：人习惯将自己的成功归于努力，将失败归于环境；却将他人的成功归于运气，失败归于能力。
4. **惯性原理**：人类倾向于帮助过去自己帮助过的人，一是拒绝错误，二是沉没成本。

## 四、两性常识
1. **沟通核心**：男与女性沟通时，最重要是接住女性的“情绪”，而不是讲道理。
2. **思维差异**：女性通常更感性，侧重于情感联结；男性通常更理性，侧重于解决问题。
3. **偏好规律**：进化心理学观点认为，女性偏爱“强”（能提供生存资源的强者），男性偏爱“色”（代表生育能力的视觉信号）。
4. **共情需求**：在亲密关系中，被看见、被理解比被教育更重要。

## 五、心理常识
1. **邓宁-克鲁格效应**：无知的人往往比有知的人更自信。
2. **孕妇效应**：当你关注某件事时，你会发现这件事在生活中到处都是。
3. **破窗效应**：如果环境中的不良现象被放任不管，就会诱使他人仿效，甚至变本加厉。
4. **晕轮效应**：如果你觉得某人某一点好，就会倾向于认为他样样都好（爱屋及乌）。

## 六、行业与商业常识
1. **二八定律 (帕累托法则)**：20% 的因素决定 80% 的结果。找到那关键的 20%。
2. **边际成本**：每多卖出一份产品增加的成本。互联网行业的伟大在于边际成本趋近于零。
3. **信息差**：商业的本质之一就是信息差，即我知道而你不知道，我知道得比你早，或者我理解得比你深。
4. **价值规律**：价格长期来看由价值决定，短期来看由供需关系决定。

## 七、自然科学常识
1. **熵增定律**：在一个孤立系统中，事物总是趋向于从有序走向无序。对抗平庸需要持续的能量输入。
2. **演化论 (生物)**：物竞天择，适者生存。存活下来的不是最强的，而是最能适应变化的。
3. **能量守恒 (物理)**：能量不会凭空产生，也不会凭空消失，只会转化。

## 八、网络常识
